سورتیں آپ کے کمپیوٹر پر محفوظ کرتا ہے۔ نہ اکاؤنٹ، نہ اشتہار، نہ ٹریکنگ۔

## انسٹال کرنا

ایک ہی کمانڈ qari **اور** mpv (وہ آڈیو انجن جو qari استعمال کرتا ہے) دونوں انسٹال کرتی ہے۔ اسے ٹرمینل میں کاپی کریں اور
Enter دبائیں۔

**Linux اور macOS**

```sh
curl -fsSL https://3mro777o.github.io/qari/install.sh | sh
```

**Windows** (اسٹارٹ مینو سے *PowerShell* کھولیں؛ ایڈمن کی ضرورت نہیں)

```powershell
irm https://3mro777o.github.io/qari/install.ps1 | iex
```

پھر `qari` لکھیں اور Enter دبائیں۔ اگر کمانڈ نہ ملے تو نئی ٹرمینل ونڈو کھولیں۔

<details>
<summary><b>انسٹال کمانڈ بالکل کیا کرتی ہے؟</b></summary>

کسی کمانڈ کو شیل میں چلانے سے پہلے آپ کو معلوم ہونا چاہیے کہ وہ کیا کرتی ہے۔ دونوں اسکرپٹس مختصر ہیں؛ انہیں
یہاں پڑھیں: [install.sh](install.sh)، [install.ps1](install.ps1)۔

**Linux** ([install.sh](install.sh))
1. اگر mpv موجود نہ ہو تو اسے آپ کے پیکیج مینیجر (`pacman`، `apt`، `dnf` یا `zypper`) سے انسٹال کرتا ہے۔
   اس مرحلے پر پاس ورڈ مانگا جاتا ہے۔ اگر یہ ناکام ہو جائے تب بھی qari انسٹال ہو جاتا ہے اور آپ کو خود mpv شامل کرنے کا کہتا ہے۔
2. GitHub Releases سے آپ کے CPU (x86-64 یا ARM64) کے لیے qari کی تازہ ترین ریلیز ڈاؤن لوڈ کرتا ہے۔
3. ڈاؤن لوڈ کو ریلیز کی `checksums.txt` (SHA-256) سے ملاتا ہے اور میل نہ کھائے تو رک جاتا ہے۔
4. `qari` پروگرام کو `/usr/local/bin` میں رکھتا ہے (پاس ورڈ مانگتا ہے)، جو ہر جگہ PATH میں ہوتا ہے۔
5. آپ کے پاس موجود شیلز کے لیے Tab تکمیل سیٹ کرتا ہے: bash، zsh اور fish۔

**macOS** ([install.sh](install.sh)): [Homebrew](https://brew.sh) استعمال کرتا ہے (پہلے اسے انسٹال کریں)۔
اسکرپٹ اس ریپوزٹری کو tap کے طور پر شامل کرتا ہے، پھر `brew install qari` چلاتا ہے، جو mpv اور Tab
تکمیل بھی انسٹال کرتا ہے۔ اس کے بعد Homebrew دونوں کو `brew upgrade` سے اپ ڈیٹ رکھتا ہے۔

**Windows** ([install.ps1](install.ps1))
1. GitHub Releases سے qari کی تازہ ترین ریلیز ڈاؤن لوڈ کرتا ہے اور اس کا SHA-256 چیک سم جانچتا ہے۔
2. `qari.exe` کو `%LOCALAPPDATA%\Programs\qari` میں رکھتا ہے (آپ کا یوزر فولڈر، اس لیے ایڈمن کی ضرورت نہیں)۔
3. اگر mpv موجود نہ ہو تو [shinchiro](https://github.com/shinchiro/mpv-winbuild-cmake) کا پورٹیبل mpv
   `%LOCALAPPDATA%\Programs\mpv` میں ڈاؤن لوڈ کرتا ہے۔
4. دونوں فولڈرز آپ کے یوزر PATH میں شامل کرتا ہے، تاکہ `qari` ہر نئے ٹرمینل میں چلے۔
5. آپ کی PowerShell پروفائل میں ایک لائن شامل کرتا ہے جو Tab تکمیل آن کرتی ہے۔

</details>

> [!NOTE]
> **Windows Smart App Control** ان پروگراموں کو روکتا ہے جن پر کوڈ سائننگ نہیں، اور qari ابھی سائن شدہ نہیں ہے۔
> اگر Windows `qari.exe` چلانے سے انکار کرے تو یہی وجہ ہے۔ دیکھیں [مسائل کا حل](#مسائل-کا-حل)۔

<details>
<summary><b>انسٹال کرنے کے دوسرے طریقے</b> (Homebrew، Scoop، تیار بائنری، Go)</summary>

**Homebrew** (macOS اور Linux):

```sh
brew tap 3mro777o/qari https://github.com/3mro777o/qari
brew trust 3mro777o/qari   # Homebrew کے نئے ورژن یہ مانگتے ہیں
brew install qari
```

**Scoop** (Windows):

```powershell
scoop bucket add qari https://github.com/3mro777o/qari
scoop bucket add extras
scoop install qari mpv
```

**تیار بائنری:** اپنے سسٹم کے لیے آرکائیو
[Releases](https://github.com/3mro777o/qari/releases) سے ڈاؤن لوڈ کریں، اسے نکالیں اور `qari` کو اپنے
`PATH` میں کہیں رکھ دیں۔ **mpv** خود انسٹال کریں (`sudo apt install mpv`، `brew install mpv`، …)۔

**Go 1.24+ کے ساتھ** (mpv بھی درکار ہے):

```sh
go install github.com/3mro777o/qari@latest
```

</details>

**ٹرمینل:** کوئی بھی جدید ٹرمینل چلے گا۔ Windows پر *Windows Terminal* استعمال کریں (Windows 11 میں
یہی ڈیفالٹ ہے)۔ عربی ناموں کے لیے دیکھیں [عربی متن](#عربی-متن)۔

### اپ ڈیٹ

انسٹال کمانڈ دوبارہ چلائیں۔ یہ ہمیشہ نئی ترین ریلیز لا کر پرانی کی جگہ رکھتی ہے؛
آپ کے پسندیدہ، پیش رفت اور ڈاؤن لوڈز برقرار رہتے ہیں۔ Homebrew والے `brew upgrade qari` بھی چلا سکتے ہیں۔

qari دن میں ایک بار GitHub چیک کرتا ہے اور نیا ورژن آنے پر نیچے فوٹر میں *"qari X is out"* (qari X آ گیا ہے) دکھاتا ہے۔

### ان انسٹال

آپ کا ڈیٹا پروگرام سے الگ ہے؛ مکمل صفائی چاہیں تو اسے بھی حذف کریں
(دیکھیں [ڈیٹا کہاں محفوظ ہوتا ہے](#ڈیٹا-کہاں-محفوظ-ہوتا-ہے))۔

<details>
<summary><b>Linux، macOS، Windows</b></summary>

**Linux**

```sh
sudo rm /usr/local/bin/qari
rm -f ~/.local/share/bash-completion/completions/qari ~/.config/fish/completions/qari.fish
sudo rm -f /usr/local/share/zsh/site-functions/_qari
rm -rf ~/.local/state/qari ~/.cache/qari ~/.local/share/qari   # آپ کا ڈیٹا، اختیاری
```

اگر zsh تکمیل `~/.zshrc` میں شامل کی گئی تھی تو وہ لائن حذف کریں جو `# qari Tab completion` پر ختم ہوتی ہے۔

**macOS**

```sh
brew uninstall qari && brew untap 3mro777o/qari
rm -rf ~/.local/state/qari ~/Library/Caches/qari ~/.local/share/qari   # آپ کا ڈیٹا، اختیاری
```

**Windows** (PowerShell)

```powershell
Remove-Item -Recurse "$env:LOCALAPPDATA\Programs\qari"
Remove-Item -Recurse "$env:LOCALAPPDATA\Programs\mpv"            # صرف اگر انسٹالر نے شامل کیا تھا
Remove-Item -Recurse "$env:APPDATA\qari", "$env:LOCALAPPDATA\qari" # آپ کا ڈیٹا، اختیاری
```

پھر دونوں فولڈرز اپنے یوزر PATH سے ہٹائیں (*Settings → System → About → Advanced system
settings → Environment Variables*) اور اپنی پروفائل سے `qari completion` والی لائن ہٹائیں (`notepad $PROFILE`)۔

</details>

## پہلے پانچ منٹ

1. **اسے کھولیں۔** `qari` لکھیں۔ آپ **Home** پر پہنچیں گے: *Continue listening*، آپ کے پسندیدہ قاری اور
   سب سے زیادہ سنے جانے والے قاری۔ اوپر کے ٹیبز یہ ہیں: `1` Home، `2` Qaris، `3` Surahs، `4` Radio،
   `5` Downloads، `6` History، `7` Settings۔ بدلنے کے لیے کوئی نمبر یا `tab` دبائیں۔

   ![Home: سننا جاری رکھیں، پسندیدہ قاری اور سب سے زیادہ سنے جانے والے قاری](docs/home.png)

2. **قاری تلاش کریں۔** `2` دبائیں، پھر `/` اور نام کا کچھ حصہ لکھیں، مثلاً `alafasi` یا `العفاسي`۔
   `j`/`k` یا تیر والی کیز سے حرکت کریں، `enter` سے کھولیں۔
3. **سورت چلائیں۔** قاری کے صفحے پر ان کی سورتیں ہوتی ہیں۔ ایک چنیں اور `enter` دبائیں۔ نیچے پلیئر
   سورت، وقت اور پروگریس بار دکھاتا ہے۔ `space` روکتا ہے، `←`/`→` دس سیکنڈ آگے پیچھے کرتے ہیں،
   `n`/`p` اگلی یا پچھلی سورت پر جاتے ہیں۔

   ![الکہف چلتے وقت قاری کا صفحہ؛ پلیئر کے فریم پر سورت کا نام ہے](docs/playing.png)

4. **اسے اپنا بنائیں۔** `f` قاری کو پسندیدہ بناتا ہے، `[`/`]` رفتار بدلتے ہیں، `t` سلیپ ٹائمر لگاتا ہے،
   `c` رنگ بدلتا ہے۔
5. **`q` سے بند کریں۔** آپ کی جگہ محفوظ ہو جاتی ہے۔ اگلی بار *Continue listening* یا `space` وہیں سے شروع کرے گا۔

الجھن ہو؟ جس اسکرین پر ہیں اس کی ساری کیز دیکھنے کے لیے `?` دبائیں۔

## رہنمائی

### آیات کی تکرار سے حفظ

چند آیات کو بار بار دہرانا حفظ کا روایتی طریقہ ہے۔ qari تقریباً 115 ریکارڈنگز میں ہر آیت کے
شروع اور ختم ہونے کی جگہ جانتا ہے، اس لیے وہ ٹھیک وہی آیات دہرا سکتا ہے جو آپ چاہتے ہیں۔

1. کوئی سورت چلائیں (مثلاً مشاری العفاسی کی آواز میں سورۃ الکہف)۔
2. `e` دبائیں۔ ایک ونڈو کھلتی ہے:

   | فیلڈ | مطلب |
   | --- | --- |
   | **From ayah / To ayah** (آیت سے / آیت تک) | دہرانے والا حصہ۔ |
   | **Each ayah** (ہر آیت) | آگے بڑھنے سے پہلے ہر آیت کتنی بار چلے (1–99)۔ |
   | **Whole range** (پورا حصہ) | پورا حصہ کتنی بار چلے (`0` = جب تک آپ نہ روکیں)۔ |
   | **Gap** (وقفہ) | ہر تکرار سے پہلے خاموشی کے سیکنڈ، تاکہ آپ خود دہرا سکیں۔ |

   فیلڈز کے درمیان `j`/`k` سے جائیں، قیمت `←`/`→` سے بدلیں یا نمبر لکھیں، پھر شروع کرنے کے لیے
   `enter` دبائیں۔

   ![آیات کی تکرار کی ونڈو](docs/repeat.png)

3. پلیئر دکھاتا ہے کہ آپ کہاں ہیں، مثلاً `ayah 3/10 · 2 of 3`۔ روکنے کے لیے `esc` دبائیں۔

**سنتے ہوئے فوری تکرار:** جب آپ کی مطلوبہ پہلی آیت شروع ہو تو `i` دبائیں، اور آخری آیت کے دوران
دوبارہ `i`۔ qari وہ حصہ دہراتا رہے گا۔ تیسری بار `i` روک دیتا ہے۔ `u` بدلتا ہے کہ ہر
آیت کتنی بار چلے (1، 2، 3، 5، 7، 10)۔

آپ کی سیٹنگز یاد رکھی جاتی ہیں، اور تکرار ڈاؤن لوڈ شدہ سورتوں پر نیٹ ورک کے بغیر بھی چلتی ہے۔ اگر کسی
ریکارڈنگ میں آیات کے اوقات نہ ہوں تو qari بتا دیتا ہے، اور اسی قاری کی کسی دوسری ریکارڈنگ کی طرف اشارہ کرتا ہے
جس میں یہ اوقات موجود ہوں (`v` سے بدلیں)۔

### رینڈم پلے اور ترکیبیں

**ترکیب** چننے کے لیے `z` دبائیں: یہ محفوظ کی ہوئی تفصیل ہے کہ رینڈم طور پر کیا چلایا جائے۔ ایک سورت ختم ہوتے ہی
دوسری رینڈم سورت شروع ہو جاتی ہے؛ ترکیب ختم ہونے تک ایک ہی قاری کی کوئی سورت دوبارہ نہیں آتی۔ `n` کوئی
اور چنتا ہے، `p` واپس جاتا ہے۔

پہلے سے موجود ترکیبیں:

| ترکیب | کیا چلاتی ہے |
| --- | --- |
| *Anything* (کچھ بھی) | مشہور قاری، روایتِ حفص، مرتّل |
| *Favorite qaris* (پسندیدہ قاری) | صرف آپ کے پسندیدہ |
| *Short surahs* (چھوٹی سورتیں) | پارہ عمّ |
| *Daily surahs* (روزانہ کی سورتیں) | الکہف، السجدہ، یٰسین، الواقعہ، الملک |
| *Mujawwad* (مجوّد) | مجوّد تلاوتیں |
| *Random radio* / *Favorite radios* (رینڈم ریڈیو / پسندیدہ ریڈیو) | لائیو ریڈیو اسٹیشن |

`a` سے اپنی ترکیب بنائیں، یا `c` سے پہلے سے موجود کسی ترکیب کی کاپی بنا کر اسے بدلیں۔ ترکیب قاریوں
(سب، مشہور، پسندیدہ یا آپ کی چنی ہوئی فہرست)، روایت، انداز (مرتّل، مجوّد، …) اور سورتوں
(سب، پارہ عمّ یا آپ کی فہرست) کے لحاظ سے فلٹر کرتی ہے۔ ایڈیٹر میں `enter` فیلڈ بدلتا ہے، `/` فہرستوں میں تلاش کرتا ہے، اور
`s` محفوظ کرتا ہے۔

### آف لائن سننا

کسی سورت کو ڈاؤن لوڈ کرنے کے لیے اس پر `d` دبائیں، یا کسی ریکارڈنگ پر دبا کر پوری ریکارڈنگ ڈاؤن لوڈ کریں (تصدیق کے لیے `d` دو بار
دبائیں)۔ **Downloads** ٹیب (`5`) قطار کو پیش رفت اور رفتار کے ساتھ دکھاتا ہے۔ ڈاؤن لوڈ شدہ سورت
ڈسک سے چلتی ہے، اس لیے ہوائی جہاز میں بھی چلتی ہے اور ڈیٹا بچاتی ہے۔ `x` ڈاؤن لوڈ حذف یا منسوخ کرتا ہے۔

![Downloads: پیش رفت اور رفتار کے ساتھ قطار، اور آف لائن سننے کے لیے محفوظ ریکارڈنگز](docs/downloads.png)

### کمانڈز اور Tab سے تکمیل

آپ شیل سے سیدھا چلانا شروع کر سکتے ہیں۔ نام ادھورے بھی ہو سکتے ہیں، انگریزی یا عربی میں؛ سورت
نمبر یا نام ہو سکتی ہے۔ اگر ایک نام کئی قاریوں سے ملتا ہو تو qari ان کی فہرست دکھاتا ہے۔

```sh
qari play alafasi 18              # مشاری العفاسی کی آواز میں الکہف، جہاں چھوڑا تھا وہیں سے
qari play alafasi                 # اس قاری سے آخری سنی ہوئی چیز دوبارہ شروع کریں
qari radio ajmy                   # ایک لائیو ریڈیو اسٹیشن
qari random "short surahs"        # کسی ترکیب سے رینڈم پلے (نام کے بغیر: آخری استعمال شدہ)
qari play alafasi yasin --no-ui   # بغیر انٹرفیس: ایک اسٹیٹس لائن، ctrl+c روکتا ہے
qari help                         # تمام کمانڈز
```

انٹرفیس چلتی ہوئی حالت میں کھلتا ہے، اور ساری کیز دستیاب ہوتی ہیں۔ `--no-ui` کے ساتھ qari آپ کے ٹرمینل کے
پس منظر میں چلتا ہے اور ایک اسٹیٹس لائن دکھاتا ہے؛ اگلی سورت ایپ کی طرح خود آتی ہے،
اور آپ کی جگہ اسی طرح محفوظ ہوتی ہے۔

**Tab تکمیل** انسٹال کمانڈ bash، zsh، fish اور PowerShell کے لیے سیٹ کرتی ہے۔
`qari play al` لکھیں اور Tab دبائیں: ملتے جلتے قاریوں کے نام آ جائیں گے؛ نام کے بعد Tab اس قاری کی
سورتیں دکھاتا ہے۔ یہ کمانڈز، آپشنز، ریڈیو اسٹیشنز، ترکیبیں اور تھیمز بھی مکمل کرتا ہے۔

![Tab تکمیل قاریوں اور سورتوں کی فہرست دکھاتی ہے](docs/cli.png)

اسے ہاتھ سے سیٹ کرنے کے لیے `qari completion bash|zsh|fish|powershell` کا آؤٹ پٹ اپنے شیل کی
اسٹارٹ اپ فائل میں لوڈ کریں۔ qari ایک بار کھولنے کے بعد تکمیل نام سیکھ لیتی ہے۔

### ریڈیو، ہسٹری اور پسندیدہ

- **Radio** (`4`): mp3quran.net کے لائیو قرآن ریڈیو اسٹیشن۔ `f` اسٹیشن کو پسندیدہ بناتا ہے۔
- **History** (`6`): آپ کی شروع کی ہوئی آخری 200 سورتیں اور اسٹیشن، دن کے لحاظ سے گروپ کیے ہوئے، اس جگہ کے ساتھ جہاں آپ
  نے چھوڑا تھا۔ `enter` اسی جگہ سے دوبارہ چلاتا ہے؛ `x` اندراج ہٹاتا ہے۔
- **Settings** (`7`): buffer (mpv سورت کا کتنا حصہ میموری میں رکھے، ڈیفالٹ 25 MB)، آواز اور رفتار
  (یاد رکھی جاتی ہیں)، ناموں کی زبان، عربی نام، اطلاعات، تھیم، روایت، ترتیب اور تکرار۔ `enter` یا `→`
  قطار بدلتا ہے، `←` پیچھے جاتا ہے۔ `--lang` جیسے آپشن اس پر غالب رہتے ہیں۔
- **پسندیدہ:** کسی قاری پر `f` اسے Home اور *Favorite qaris* ترکیب میں شامل کر دیتا ہے۔
- **سب دکھائیں:** ڈیفالٹ طور پر آپ مکمل ریکارڈنگ والے مشہور قاری دیکھتے ہیں۔ `a` سب
  دکھاتا ہے، ادھوری اور کم معروف ریکارڈنگز سمیت۔ `s` مقبولیت، نام یا حالیہ
  اپ ڈیٹ کے لحاظ سے ترتیب دیتا ہے، `w` روایت (حفص، ورش، قالون، …) کے لحاظ سے فلٹر کرتا ہے، `v` قاری کی ریکارڈنگز میں سے ایک چنتا ہے۔

### تھیمز

`c` دبائیں: جیسے جیسے آپ حرکت کرتے ہیں پوری اسکرین ہر تھیم کا پیش منظر دکھاتی ہے، `enter` اسے رکھتا ہے، `esc` واپس جاتا ہے۔
کوئی تھیم پس منظر نہیں رنگتی، اس لیے شفاف ٹرمینل شفاف ہی رہتا ہے۔

| تھیم | انداز |
| --- | --- |
| `mihrab` | **Mihrab** (محراب، ڈیفالٹ): گرم سنہرا سونا، سنگِ مرمر اور سیج سبز |
| `andalus` | **Al-Andalus** (اندلس): الحمرا کا ٹیراکوٹا، چمکدار فیروزی اور ہاتھی دانت |
| `lapis` | **Samarkand Lapis** (سمرقند کا لاجورد): تیموری لاجوردی نیلا، سونے کا ورق اور چاندنی ریشم |
| `madinah` | **Madinah** (مدینہ): روشن زمرّدی، ہلکا پیتل اور گرم موتی |
| `contrast` | **High Contrast** (زیادہ کنٹراسٹ): سفید، شوخ سنہرا اور برقی فیروزی |

![تھیم چننے والا Al-Andalus کا پیش منظر دکھاتے ہوئے](docs/theme.png)

### میڈیا کیز

Linux پر qari خود کو MPRIS پلیئر (`org.mpris.MediaPlayer2.qari`) کے طور پر رجسٹر کرتا ہے، اس لیے کی بورڈ کی میڈیا کیز،
ڈیسک ٹاپ وجٹس اور `playerctl -p qari play-pause` اسے کنٹرول کرتے ہیں، اور ہر نئی سورت پر ایک نوٹیفکیشن آتا ہے۔
macOS اور Windows پر ابھی میڈیا کیز نہیں ہیں؛ نوٹیفکیشن پھر بھی آتا ہے۔

### عربی متن

ڈیفالٹ طور پر نام انگریزی میں دکھتے ہیں، اور آپ ہمیشہ عربی میں تلاش کر سکتے ہیں: `البقره` سے Al-Baqarah مل جاتی ہے۔
`--lang` قاریوں اور سورتوں کے نام API کی پیش کردہ 21 زبانوں میں سے کسی میں بھی بدل دیتا ہے (`--lang ar`،
`--lang fr`، `--lang ur`، …؛ `--languages` ان کی فہرست دیتا ہے)۔ `--arabic` انگریزی ناموں کے ساتھ سورتوں کے
عربی نام بھی دکھاتا ہے۔

عربی کے لیے ایسا ٹرمینل چاہیے جو دائیں سے بائیں متن سپورٹ کرے: Konsole، GNOME Terminal اور دوسرے VTE
ٹرمینل، WezTerm، mlterm، Windows Terminal۔ دوسرے ٹرمینلز میں عربی حروف الٹے
یا الگ الگ دکھ سکتے ہیں۔

شارٹ کٹس کی کی جگہ کے مطابق چلتے ہیں، اس لیے عربی کی بورڈ لے آؤٹ پر بھی کام کرتے ہیں: `ض` بالکل
`q` کی طرح بند کرتا ہے، `ظ` بالکل `/` کی طرح تلاش کرتا ہے۔

### بلاک شدہ نیٹ ورکس

کچھ اسکول اور دفتری نیٹ ورک mp3quran.net کو بلاک کرتے ہیں۔ اگر فہرستیں لوڈ نہ ہوں تو کوئی ایسی پراکسی استعمال کریں جس کی
آپ کو اجازت ہو:

```sh
qari --proxy socks5://127.0.0.1:1080
```

mpv SOCKS پراکسی استعمال نہیں کر سکتا، اس لیے qari آڈیو کو ایک چھوٹے مقامی ریلے کے ذریعے mpv تک پہنچاتا ہے؛ آگے پیچھے کرنا
پھر بھی چلتا ہے، اور ڈاؤن لوڈز بھی اسی پراکسی سے ہوتے ہیں۔

## تمام کیز

اس فہرست کے لیے ایپ میں `?` دبائیں۔ کیز mpv، cmus اور vim کے طرز پر ہیں۔

| `enter` / `l` | کھولیں یا چلائیں |

| `/` | موجودہ فہرست میں تلاش (انگریزی، عربی یا سورت نمبر) |
| `o` | جو چل رہا ہے اس پر جائیں |
| `space` | چلائیں / روکیں (کچھ نہ چل رہا ہو تو آخری سورت جاری کرتا ہے) |

## آپشنز

```text
qari [options]
qari play <qari> [surah] [--no-ui]
qari radio <station> [--no-ui]
qari random [recipe] [--no-ui]
qari completion bash|zsh|fish|powershell

--lang CODE    language for qari and surah names (default eng; see --languages)
--languages    list the languages the API offers
--theme NAME   color theme (see --themes; overrides the saved choice)
--themes       list the themes
--proxy URL    send all traffic through a proxy, e.g. socks5://127.0.0.1:1080
--arabic       also show the Arabic surah names
--no-notify    no desktop notification when a surah starts
--no-ui        with play, radio or random: play without the interface
--version      print the version
```

`QARI_LANG`، `QARI_THEME` اور `QARI_PROXY` یہی ڈیفالٹس انوائرنمنٹ سے سیٹ کرتے ہیں۔

## ڈیٹا کہاں محفوظ ہوتا ہے

| کیا | Linux / macOS | Windows |
| --- | --- | --- |
| پسندیدہ، پیش رفت، ترکیبیں، ہسٹری، سیٹنگز | `~/.local/state/qari/state.json` | `%AppData%\qari\state.json` |
| کیٹلاگ کیش | `~/.cache/qari/` (macOS پر `~/Library/Caches/qari/`) | `%LocalAppData%\qari\` |
| ڈاؤن لوڈ شدہ سورتیں | `~/.local/share/qari/` | `%LocalAppData%\qari\` |

Linux پر `XDG_STATE_HOME`، `XDG_CACHE_HOME` اور `XDG_DATA_HOME` متغیرات ان فولڈرز کی جگہ بدل دیتے ہیں۔

## رازداری

qari میں کوئی اکاؤنٹ نہیں اور یہ کوئی اینالیٹکس نہیں بھیجتا۔ یہ صرف دو جگہوں سے رابطہ کرتا ہے: mp3quran.net (فہرستیں،
آڈیو اور آیات کے اوقات) اور GitHub (دن میں ایک بار، یہ دیکھنے کے لیے کہ نئی ریلیز آئی ہے یا نہیں)۔ جو کچھ یہ
یاد رکھتا ہے وہ آپ کے کمپیوٹر پر ہی رہتا ہے۔

## مقبولیت کا ڈیٹا

mp3quran.net سننے کی تعداد شائع نہیں کرتا۔ مقبولیت ایک اسنیپ شاٹ سے آتی ہے جو
[`internal/popular/popular.json`](internal/popular/popular.json) میں ہے، اور اسے
[`tools/genpopular`](tools/genpopular/main.go) ان ذرائع سے بناتا ہے:

- **سننے کی تعداد** جو [way2quran.com](https://www.way2quran.com/en/reciters?sortBy=-totalListens) شائع کرتا ہے
- **"مشہور"**: قاری [quranicaudio.com](https://quranicaudio.com) یا
  [quran.com](https://quran.com) پر بھی موجود ہو، یا way2quran انہیں ٹاپ قاری قرار دے

ویب سائٹس کے درمیان قاریوں کو ان کے عربی اور انگریزی ناموں سے ملایا جاتا ہے۔ اسنیپ شاٹ تازہ کرنے کے لیے
`go run ./tools/genpopular` چلائیں۔

## سورس سے بنانا

Go 1.24+ اور mpv درکار ہیں۔

```sh
git clone https://github.com/3mro777o/qari && cd qari
go build -o qari . && ./qari
go test ./...
```

کوڈ: `internal/api` (mp3quran.net کلائنٹ اور کیش)، `internal/player` (JSON IPC پر mpv)،
`internal/store` (محفوظ حالت)، `internal/ui` ([Bubble Tea](https://github.com/charmbracelet/bubbletea)
انٹرفیس)۔ جب کوئی `v*` ٹیگ پُش ہوتا ہے تو [GoReleaser](https://goreleaser.com) ریلیزز بناتا ہے۔
